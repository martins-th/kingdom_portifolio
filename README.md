# O Projeto
uma criação inicial para pôr em prática os estudos de HTML, CSS e JS. A ideia é criar um site que transmita a experiência de estar no menu do jogo Kingdom Hearts. No momento o site será meu portifólio pessoal.

# Configurações
## Ferramentas utiilzadas
HTML, CSS, JS, NODE JS
## Configuração do ambiente
Utilizando o Node junto do framework express para aplicação do backend, template engine Handlebars, GSAP para as animações.
## Estrutura
Dividido nas pastas public, que contem os conteúdos estáticos, e na views, que contem os arquivos handlebars.
